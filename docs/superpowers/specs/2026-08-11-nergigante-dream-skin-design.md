# 灭尽龙 Codex Dream Skin 主题素材设计

## 目标

为本机 `/Applications/Codex Dream Skin.app` 制作一套可导入的暗黑 UI 主题素材，主题灵感来自《怪物猎人》的灭尽龙。素材需要适合长期使用，保证 Codex 左侧侧栏和文字内容清晰可读。

## 视觉方向

- 风格：暗黑 UI 适配感，低饱和、压迫但克制。
- 主色：黑曜石黑、灰紫、暗红棘刺、少量冷紫边缘光。
- 背景布局：灭尽龙主体偏右，左侧保留深色低细节安全区，避免覆盖侧栏。
- 材质：粗粝鳞片、断裂棘刺、低对比岩石尘雾；避免高亮噪点和过度复杂的背景。
- 配色基准：背景 `#0B0A0F`，面板 `#15131A`，主色 `#8B526C`，高亮 `#B83F55`，文字 `#E8E1E5`。

## 交付素材

1. `background.png`：1920×1080 的主题主背景，主体右置，适合 Codex Dream Skin 的左侧安全区。
2. `sidebar-pattern.png`：1024×1024 的可平铺侧栏暗纹，仅使用抽象棘刺、鳞片和阴影，不放置完整角色。
3. `decorative-spines.png`：1600×400 的顶部/底部装饰元素，包含灭尽龙棘刺、碎鳞和暗红能量纹；生成时使用纯色抠图底色并转换为透明 PNG。
4. `theme.json`：Codex Dream Skin 主题元数据、颜色、文案和背景入口。

## 使用约束

- 不添加文字、Logo、水印或界面控件。
- 背景和侧栏纹理不能使用大面积纯白或高亮紫色。
- 背景左侧应保持足够的暗部对比，正文文字使用浅色时仍清晰。
- 装饰元素需要与背景共享同一套材质和光照方向。
- 资源文件保存在当前工作区，并打包为可导入的主题 ZIP；不覆盖已有主题文件。

## 验收标准

- 三类图像风格统一，色彩与材质相互匹配。
- `background.png` 尺寸为 1920×1080；`sidebar-pattern.png` 尺寸为 1024×1024；`decorative-spines.png` 含透明区域。
- `theme.json` 指向实际存在的背景文件，JSON 可解析。
- 主题目录可压缩为 Codex Dream Skin 可识别的 ZIP 包。
